# Insider & Corporate Intelligence

When analyzing corporate activity:
1. Run `fetch_form4_signals_tool` to detect executive/director stock accumulation or dumping.
2. Call `fetch_lobbying_signals_tool` to map lobbying spend surges to relevant policy updates.
